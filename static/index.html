FMS & evidence

Evidence groups: compare screenshots

Create a group for each issue (for example, FMS EFOB before and after a waypoint change). Link any number of screenshots and place them in order. Use a group-level remark to explain Screenshot 1 → 2 → 3. Each image retains its own UTC, GPS, altitude and fuel-flow context. Groups appear together in the PDF.

You can link screenshots later or reorder them using the arrows. Ungrouped screenshots are preserved.

Screenshot and GPS evidence in one step

Press Ctrl + Shift + F10 anywhere: the monitor containing MSFS is detected and captured, even when the browser is on another monitor. UTC, GPS, altitude, speed, FOB, engine FF and wind from the latest SimConnect sample are stored with the image. You can edit the remark later. Screenshots can be captured without selecting an issue category. No automatic background screenshots are taken.

Checking hotkey

GPS comes from the latest SimConnect sample (typically up to ~2.5 seconds before capture); the actual sample age is stored. No position is invented if data is missing or stale. Automatic mode locates the simulator window at capture time and selects the display it occupies most. If MSFS is missing or minimized, no screenshot is taken; choose a manual mode only after verifying the correct display. A browser or other window covering MSFS on that same display may still appear in a monitor screenshot. Exclusive fullscreen may produce a black capture; upload a manually captured image if necessary.

Attach existing screenshots (optional)

Screenshots uploaded later cannot be assigned a reliable historical GPS position unless linked to an existing GPS event. Capture the pre-pushback FMS fuel prediction separately. For a fuel-flow or EFOB event, save the observation first and then select it under “Link to observation”. Multiple screenshots can be uploaded together and will appear in the PDF.

OIS Autosave (.bin)

Create the save in the A350 OIS using FLT OPS MENU → AUTOSAVE → SAVE NOW, then attach it here. The .bin file is included separately in the ZIP; its contents cannot be shown as a PDF screenshot.
